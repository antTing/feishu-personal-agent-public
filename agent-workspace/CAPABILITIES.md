# Agent 能力说明

这是给当前 Codex Agent 读取的脱敏能力说明。

## 当前可用

- 阅读、搜索、分析当前工作区中的代码和文档。
- 解释实现、定位问题、提出方案和进行只读检查。
- 通过已授权的飞书工具读取允许访问的文档数据。
- 在用户明确要求且运行时权限允许时，执行范围明确的开发任务。

## 当前限制

- 默认运行在只读沙箱中，不能创建或修改工作区文件。
- 不读取当前工作区之外的文件。
- 不输出密钥、Token、Cookie、完整本地路径或内部工具日志。
- 不直接操作生产数据库、Docker Socket、Kubernetes 或云基础设施。
- Git、部署、删除、发消息、权限变更和其他外部副作用需要针对具体动作获得明确批准。

飞书企业自建应用收到的普通非空文本消息会通过 cc-connect Bridge 进入 Codex；能力、费用、帮助、任务状态、停止和审批等本地指令由 Connector 先处理。本文件用于回答这些场景的权限边界。

Connector 可以从白名单群接收获准机器人明确 @ 当前机器人的转交消息，并提取纯文本、富文本、卡片文字和链接。任务转入后会立即回复已接收，随后持续更新执行状态；图片、文件和语音本体需要单独配置下载与解析能力。

## 当前费用

- 飞书企业自建应用只是消息通道，不会自动调用智能体模型。
- 若由另一个智能体先生成转交内容，上游智能体可能使用自己的额度，随后 Codex 仍会产生独立的模型用量。
- Connector 与 cc-connect 没有按消息软件费。
- Codex 的费用取决于安装者选择的登录方式和账户方案；Connector 不应声称某台机器固定使用 API Key 或订阅额度。

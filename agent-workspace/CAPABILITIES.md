# Agent 能力说明

这是给本地 Codex 读取的脱敏能力说明。

## 当前可用

- 阅读、搜索和分析已授权工作区；
- 解释实现、定位问题、提出方案；
- 在权限允许时处理图片、文件和链接；
- 在主人明确批准后执行范围清晰的开发任务。

## 当前限制

- 不读取已授权工作区之外的文件；
- 不输出密钥、Token、Cookie、完整本地路径或内部工具日志；
- 不直接操作生产数据库、Docker Socket、Kubernetes 或云管理员接口；
- Git、部署、删除、外发和权限变更都需要对具体动作获得明确批准；
- 工作区可以没有 Git，不因缺少 `.git` 自动初始化仓库。

飞书企业自建应用消息由 cc-connect 原生 Feishu 适配器进入 Codex。Aily 可以作为上游调度器，只转交需要本机的任务；`DS/T` 编号和来源会话映射由 Aily 维护。

## 费用

- Aily 可能消耗自己的套餐或模型额度；
- cc-connect 没有按消息软件费；
- Codex 的费用取决于安装者的登录方式、账户和产品条款；
- 不根据机器人回答推断真实账单。
